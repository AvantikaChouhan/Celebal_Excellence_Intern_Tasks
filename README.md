# ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/AvantikaChouhan/Celebal_Excellence_Intern_Tasks
```

Navigate to the project folder

```bash
cd Celebal_Excellence_Intern_Tasks
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the required assignment/project from its respective week folder.

Example:

```bash
cd Week-8
```

Generate Data

```bash
py scripts/generate_data.py
```

Clean Data

```bash
py scripts/clean_data.py
```

Load Database

```bash
py scripts/load_database.py
```

Generate Report

```bash
py scripts/report_cli.py
```

Run Edge Case Tests

```bash
py scripts/edge_case_tests.py
```
